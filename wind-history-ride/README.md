# 《乘風騎行》Riding the Wind — 風力發電五千年

> 「風一直都在；人類花了五千年，學會騎上它。」

**《乘風騎行》** 是一支 `2:58`（`178.0 s`、`120 BPM`、`1920×1080`）的 **100% 程式即時生成動畫時間軸**：
一隻黑面琵鷺騎著腳踏車、車尾插著小風車，沿著一條連續的道路穿過 **20 幅畫框**——
每一幅都是風力利用史上的一站，而且用「那個時代、那個地方」的藝術媒材畫成；
車尾的小風車會隨時代變成帆、垂直軸風車、四翼柱式風車、多葉片汲水風車、兩葉、三葉轉子……

做法參考 [Pelican Test（鵜鶘測試）](https://github.com/orbitoo/pelican-test) 的概念——
**確定性純函數 `renderAt(t)`、一條連續道路穿越時代畫框、程序化配樂**——
但畫面、角色、程式與內容皆為本專案原創，並改為講述風力發電的發展史，方便課堂教學。

## 快速開始

不需要建置，任何靜態伺服器即可：

```bash
cd wind-history-ride
node tools/serve.mjs          # http://127.0.0.1:4173/
```

- `index.html`：互動播放器（空白鍵播放／暫停、←/→ 微調 0.5 秒、Shift 2 秒、M 靜音、F 全螢幕；勾選 **每站暫停** 可在每一站中段自動停下講解）
- `gallery.html`：二十站畫廊與史料出處
- `render.html`：1920×1080 渲染宿主（給下面的工具用）

字型由 Google Fonts 載入（Noto Serif/Sans TC、霞鶩文楷 TC 等）；離線時自動退回系統字型。

### 工具（需要 Node 20+ 與 Playwright/Chromium）

```bash
npm install                                         # 只裝 esbuild（打包用）
node tools/shot.mjs film 10 out/frame.png           # 任一時刻的整格畫面
node tools/shot.mjs panel nile 0,4,7.9 out/nile --timing   # 單一時代畫框 + 效能
node tools/sheet.mjs                                # 二十站縮圖總表 out/sheet.png
node tools/check-audio.mjs                          # 配樂量測（響度、峰值、確定性 --determinism）
node tools/render-audio.mjs                         # 匯出配樂 out/soundtrack.wav
node tools/render.mjs --fps 30 --audio out/soundtrack.wav   # 輸出 MP4（需要 ffmpeg）
node tools/build.mjs                                # dist/ 單檔版 index / gallery / render
```

## 架構

```text
wind-history-ride/
├── index.html / gallery.html / render.html
├── public/style.css
├── src/
│   ├── main.js            純函數 renderFilmFrame(ctx, t)、播放器 UI、渲染 API
│   ├── data/eras.js       二十站的史料、說明、出處、配色、畫框、轉子型式、配樂配方
│   ├── beat/timeline.js   120 BPM 音樂時鐘、片長結構、騎士連續運動（C2 連續的起步）
│   ├── beat/camera.js     平穩跟拍攝影機（無晃動、無變焦抽動）
│   ├── rig/spoonbill.js   黑面琵鷺＋腳踏車骨架（雙骨解析 IK 踩踏）與各時代小風車
│   ├── kit/               共用工具：確定性亂數與雜訊、靜態烘焙快取、道路、畫框、展牌、字型
│   ├── scenes/            序章、20 個時代、終章時間軸
│   └── audio/             程序化 Web Audio 配樂（OfflineAudioContext 合成全片）
├── tools/                 靜態伺服器、截圖、縮圖總表、MP4 / WAV 輸出、單檔打包
└── SCENE_GUIDE.md         場景模組的介面約定（新增或改寫一站時必讀）
```

**設計原則**

- **確定性**：任一時刻 `t` 的畫面只由 `t` 決定（無 `Math.random`、無計時器狀態），可任意拖曳、逐格離線輸出、平行渲染。
- **連續性**：道路在每一幅畫框的左右邊緣都固定在 `y = 700`、斜率 0；騎士以每 8 秒一幅的固定速度前進，跨框時同一台腳踏車在兩種畫風之間「換裝」。
- **正確性**：畫面中的機械（軸向、葉片數、塔架、迎風/背風）依史料繪製；文字資料附出處。
